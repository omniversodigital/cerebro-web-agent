# 🌐 Cerebro Autonomous Web Agent

**Autonomous web scraping, browser automation, and data pipeline agent with vector memory (Qdrant) and fallback routing.**

---

## 🚀 Key Capabilities

- **AI-Powered Web Automation**: Multi-step autonomous browser navigation and DOM inspection.
- **Vector Memory Integration**: Qdrant embedding storage for semantic search and web knowledge retrieval.
- **Resilient Fallback Routing**: Multi-provider fallback router across local and cloud LLM endpoints.
- **Workflow Orchestration**: n8n integration for trigger-based automation loops.

---

## 🛠️ Tech Stack

- **Core Engine**: Python 3.11+, Playwright, BeautifulSoup4
- **Vector DB**: Qdrant
- **Automation**: n8n, Docker Compose
